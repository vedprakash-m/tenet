# `pkg/conformance/card` — independent conformance cases for `CP-0051` (`tenet verify --run-checks` / `--bundle` / `--record` / proof card)

Written independently from `contracts §1` and `§5` (`tenet/specs/tech-spec/contracts.md:18, 83–84`), `CI §1–§4` and `§10` (`tenet/specs/tech-spec/ci.md:9–170, 243–263`), `ALG-07` (`tenet/specs/tech-spec/algorithms.md:104–133`, with every rule capped at `advise` in alpha.0), `ALG-14` (`tenet/specs/tech-spec/algorithms.md:189–196`), `kit/schemas/{bundle,proof-card,tenet-yaml}.json`, the `CP-0051` build contract (`tenet/specs/plan/alpha.0b.md:65–90`), and the round 4 and round 6 specification answers (`tenet/packets/CP-0051-proof-job-card-and-records-ref/escalations/{answers-r4,answers-r6}.md`).

## Running and validating a case

Each case folder holds `input.json`, an exact `expected.json`, and an exact byte-for-byte `expected.md`:

- `input.json.event` carries the `VerifyEvent` payload (`kind: "workflow_run"`, `repository`, `run: {id, attempt, workflow, head, repository, startedAt}`, `pulls`, `base`, `pr_body`, `records_push`, and the 8-key `evaluation_input` tuple `{repository, work, tested_commit, base, acceptance_digest, implemented: [{id, blessed_digest}], policy_blob, tenet_version}` from `contracts §1`).
- `input.json.bundles` is an array of `{bundle, files}` entries where every `bundle` validates against `kit/schemas/bundle.json` and `decodeBundle()`, and `files` maps each `check.report` path (`reports/unit.xml`) to its raw JUnit XML string whose SHA-256 matches `check.report_sha256` and parses through `parseBundledReport()`.
- `input.json.repo` carries `baseFiles` and `headFiles` (plus `previousBaseFiles` in `n06-policy-load-failure-fallback`, where `baseFiles["tenet.yaml"]` is invalid so the recorder falls back to `previousBaseFiles["tenet.yaml"]` per `answers-r6.md` Q3). Tests attributing coverage to `C-1` tag both `[C-1]` and `[AB-1]` on the test declaration and `<property name="tenet.case" value="C-1"/>` in the JUnit XML report per `answers-r6.md` Q2.
- `expected.json` holds `{ok, conclusion, wrote, card}`, validating against `kit/schemas/proof-card.json`.
- `expected.md` holds the complete LF-terminated Markdown string produced by `renderCard(expected.card)`.

Run `node tenet/packets/CP-0051-proof-job-card-and-records-ref/evidence/verify-card-bundles.mjs` to validate every `input.json`, `expected.json`, and `expected.md` against `bundle.json`, `tenet-yaml.json`, `proof-card.json`, `decodeBundle`, `parseBundledReport`, and `renderCard`.
