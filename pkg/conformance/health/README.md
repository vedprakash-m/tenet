Each directory contains `input.json` with the relevant target policy, baseline, pinned facts, diff or repository snapshot, and references to any raw report files. Case labels beginning `p` describe valid or intentionally advisory situations. Labels beginning `n` describe regressions, invalid evidence, missing required inputs, or policy refusals. `expected.json` is an exact projection using the [independent suite rules](../INDEPENDENT.md). Case operation names and projection keys are fixture fields. The runner maps them to CP-0039's public outputs and internal observations. An omitted projection field makes no assertion about that field.

Raw JSON, SARIF, LCOV and Cobertura are separate files so the reader sees original bytes. The purposely malformed report is a text file. `digest_inputs` records the objects used to compute literal prefixed SHA-256 values over RFC 8785 UTF-8. Fixed commit IDs are synthetic. For `map-diff` cases, construct the described Git snapshots and run the shared mapper and applicable consumer. `hunks` in its expected projection is the single changed file's sequence of old and new starts and counts. Generate the `n06` snapshot from the two explicit counts and prefixes rather than committing 2,002 files.

The `n13`–`n15` report generators and the variable-size card cases are inputs awaiting a ruling on exact bounds and bytes. A row with a question ID has no expected file. Preserve the other cases byte for byte when wiring the builder's harness.
