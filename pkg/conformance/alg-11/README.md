# `pkg/conformance/alg-11` — independent conformance cases for `ALG-11` and `CP-0048` (`tenet onboard`)

Written independently from `ALG-11` (`tenet/specs/tech-spec/algorithms.md:174–176`), `OB §1` (`tenet/specs/tech-spec/onboarding.md:9–45`), `contracts §4` (`tenet/specs/tech-spec/contracts.md:74–81`), `kit/schemas/{inventory,assignment}.json`, the `CP-0048` build contract (`tenet/specs/plan/alpha.0b.md:50–63`), and the round 4 specification answers (`tenet/packets/CP-0048-onboarding/escalations/answers-r4.md`).

## Running a case

Each case folder holds `input.json` and an exact `expected.json` (no `$assert` projection markers remain):

- `input.json.repo.files` is the committed repository snapshot at `repo.revision` (`HEAD`, or `null` when the repository has no commits yet); `input.json.repo.worktreeOnly` holds uncommitted or untracked working-tree files (such as a local test report or dirty source edits); `input.json.repo.committedDates` provides the last-commit date per documentation file.
- `input.json.options` carries the `onboard({inventoryOnly, refresh, layout})` arguments.
- `expected.json` holds the complete expected `{ok, exitCode, preflight, inventory, findings, assignment}` (or `{ok: false, exitCode, errors}` on failure), with `inventory` and `assignment` validating against `kit/schemas/inventory.json` and `kit/schemas/assignment.json`.
