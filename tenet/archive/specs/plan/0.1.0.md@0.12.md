**CP-0022 · Reference agent cards for the careful lane** · R-012 (shaper, test writer, builder, judge), R-013, R-015 · an `agent` packet
1. *Needs:* alpha.2; the agent card schema (CP-0004); the loop contract (AG §5); AG.
2. *Owns:*
   - `kit/agents/{shaper,test-writer,builder,judge}.md`
   - skills `write-a-definition` and `write-independent-tests`
   - `kit/criteria/`, the judge protocol, the `agent check` command
   - the 5-case activation tests in `pkg/evals/{judge,test-writer}/`
8. *Proving:*
   - `tenet agent check` passes on all four cards and fails on a card that widens its tools
   - the test writer's card is a different definition from the builder's (independence `different-definition`)
   - the judge and test writer pass their activation tests (advisory)

**CP-0020 · The `agents-md` binding and work commands** · R-014, R-036, R-040, R-042, R-044, R-046, R-047, R-105, R-107, R-111, R-124, R-156
1. *Needs:* CP-0022; TS §11; C §8 (0.1.0 commands); AG §5.
2. *Owns:* `build --target agents-md`; the `minimal` pack's station loops (`define`, `build`, `verify`) and the `fix` loop, with their static checks (AG §5); the commands `new`, `move`, `status`, `task done`, `resume`, `decide`, `resolve`, `escalate`, `lease`, `release`, `assign`, `result`, `inspect`, `record`, `skill list`; compiling agent cards for hosts; stop thresholds (`stop.failing_evaluations`); an advisory critic; pinned independent tests in the careful lane; run records with actor chain and cost.
8. *Proving:* a real host session works a quick and a careful packet end to end: the shaper writes the definition, the Owner approves it, the test writer's tests are pinned before the builder starts, and the judge reviews; the cards compile for two hosts; a card failing three evaluations in a row stops the work and opens an escalation.

**CP-0056 · experiment · Spike D: headless agent hosts** · R-041 (part) · time box 2 days, alongside CP-0022
1. *Needs:* alpha.2.
2. *Owns:* a ledger entry: for the Claude Code, Codex, Copilot and Gemini command-line tools, their headless flags, authentication locally and in CI, structured output, exit codes, usage and cost reporting, tool and path restrictions, and cancellation; the adapter capability table (AG §6); the two adapters to build first. *Fallback:* the `command` adapter only.

**CP-0055 · Reference runner** · R-041 (part), R-043 (part), R-224
1. *Needs:* CP-0020, CP-0056; AG §5–§6; C §8.
2. *Owns:* `runner/` (the package `@vedprakash-m/tenet-runner`), the `command` adapter and the two host adapters CP-0056 selects, `test/runner/`.
8. *Proving:*
   - On a real repository, `tenet-runner start` takes a careful change to an open pull request with its card, stopping only for the definition approval, with each host adapter.

   - `stop` leaves no orphan process or worktree.
   - The `command` adapter drives a scripted fake agent on three platforms.
