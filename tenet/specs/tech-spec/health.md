## 1. Health schemas and inputs

- **Committed baseline (`kit/schemas/health-baseline.json`, `.tenet/health-baseline.json` under `protect`):** `{schema_version: 1, entries: {"<area>::<indicator>": {area, indicator, kind: "scalar" | "finding_set", origin?, tool, tool_version, config_digest, scope_digest, value?, numerator?, denominator?, allowed_counts?: Record<fp_key, int>=0}}}`. Read solely from target `<base>` (`git show <base>:.tenet/health-baseline.json`) and changed only by explicit reviewed `change-policy` commits (`origin: observed` at adoption or explicit re-baselining). Missing entry for an applicable `enforce` indicator fails `TN-HEALTH-BASELINE` at `verify`/`assure` (optional `observe`/`advise` stays `unknown`).
- **Authoritative single-report inputs (`kit/schemas/health-input.json`):** `checks.<name>.report` accepts `tenet-health-json | sarif | lcov | cobertura`; strictly one raw report per `checks.<name>` run and one authoritative check per indicator (`no matrix shard combining` — conflicting duplicates fail `TN-HEALTH-INCOMPATIBLE`). Reader bounds enforce `ci.md §3` inclusively (`<= 52,428,800` bytes = 50 MiB, root JSON/XML node at depth `1` `<= 64`, `<= 20,000` raw findings/edges/results/records before deduplication): single-report parse, schema, unknown-key or limit violations fail **`TN-REPORT-MALFORMED`**, while package/bundle-level aggregate limits fail **`TN-RECORD-BUNDLE`**.
  - **Tool identity (`tool: {name, version, config_digest}`)** comes **solely from `<base>` `tenet.yaml`'s `checks.<name>` declaration**, never from the report (`runs[].tool.driver` ignored) and never copied from baseline.
  - **`tenet-health-json` and `sarif` (the only formats eligible for `enforce`):** must supply `{coverage: {complete, analyzed_paths/modules}, scope_digest}` checked against `<base>` `inputs[]` (in SARIF `2.1.0`, `runs.length >= 1` and every `runs[i].properties` MUST supply `{coverage: {complete, analyzed_paths/modules}, scope_digest}` + optional `invocations[].executionSuccessful`; missing property -> `TN-REPORT-MALFORMED`, mismatched/cross-run `scope_digest` or `inputs[]` drift -> `TN-HEALTH-CONFIG-CHANGED`, any run `complete: false` or failed invocation -> overall `complete: false` failing `TN-GATE-UNKNOWN` in `enforce` else `unknown`; when all runs are complete with equal `scope_digest`, union `analyzed_paths/modules` and aggregate/deduplicate all `runs[].results[]` sorted canonically). Any report supplying `thresholds`/`tolerance`/`max_new`/`mode`/`waived` or forbidden keys fails `TN-REPORT-MALFORMED`.
  - **Architecture graph contract (`architecture_graph`):** allows only `{modules: [id], edges: [{from_module, to_module}], module_map_digest?: "sha256:..."}` (`reported_module_map` or inline path/area definitions are forbidden -> `TN-REPORT-MALFORMED`); a schema-valid mismatching `module_map_digest !== sha256(RFC 8785 health.architecture.modules)` fails **`TN-HEALTH-PROVENANCE`**.
  - **Raw `lcov` and `cobertura` (`metric_cap = "advise"` — advisory only, 0 gate credit):** normalize identically into `area` scalar trends (`numerator`/`denominator`), populating `tool` from `<base>` `tenet.yaml` and naming missing report metadata explicitly (`missing_metadata: ["coverage.complete", "scope_digest", ...]`), never failing `TN-REPORT-MALFORMED` for missing Tenet fields, subject to `ci.md §5:185`'s honest limit until `CP-0064`.

## 2. Health evaluation and tamper routing (ALG-16)

1. **Precedence, applicability & check requiredness (`R-202`, `R-204`, `ALG-07`):**
   - `effective_mode(I) = min(rule_mode("health-ratchet"), I.mode ?? "observe", metric_cap(I))`, where new PR indicators default `observe` below `verify` and refuse `TN-POLICY-RULE-DECISION` at `verify`. Child `ALG-06` layers never narrow `scope_globs` or add `exclude_globs` (`TN-POLICY-LOOSEN`).
   - `metric_cap(I) = "advise"` for scalars with `population: "touched" | "sampled_runs"`, **all** `finding_set` indicators with `scope: "touched_lines"`, and raw `lcov` / `cobertura` reports.
   - Resolve applicability first on pinned `<base>` facts via `ALG-15` (touched paths or declared area dependencies per `R-202`): genuinely unknown applicability remains visible (`TN-GATE-UNKNOWN`); inapplicable indicators resolve `not-applicable`.
   - `checks.<name>` is mandatory (`verify` fails missing/malformed/`exit !== 0`) iff in `lane_checks` OR consumed by an **applicable** indicator `I` with `effective_mode(I) === "enforce"`.
2. **Comparison math (`R-175`, `R-176`):**
   - **`scalar` (`population: "area"` only `enforce`-eligible):** `scope_digest = sha256(RFC 8785 {kind: "scalar", area, area_paths, area_source_digest, scope_globs, exclude_globs, unit})`. Compare via exact `BigInt` cross-multiplied rationals against `tolerance: {kind: "absolute" | "relative-pct", value >= 0}`; `relative-pct` at `baseline === 0` gives `0` slack; `denominator === 0` returns `not-applicable` iff `expected_paths` empty, else `TN-GATE-UNKNOWN`.
   - **`finding_set` (`touched_files` and `area` `enforce`-eligible; `touched_lines` capped `advise`):** `fp_key = sha256(RFC 8785 {rule_id, file, symbol: symbol ?? "", snippet_hash})` after `CRLF->LF` and collapsed horizontal whitespace; deduplicate exact location `{rule_id, file, line, end_line, symbol, snippet_hash}` to `1`. `scope_digest = sha256(RFC 8785 {kind: "finding_set", area, area_paths, area_source_digest, scope, scope_globs, exclude_globs, rule_scope, check})`. Check exact non-masking regression predicate against `policy.max_new` pinned in `<base>` `tenet.yaml` (count-based `max(0, current_ref[k] - allowed_counts[k])` for `referenced_paths[]`, no cross-area `-M50%` credit, no 20-line bypass, `"baseline stale"` advisory if counts dropped):
     $$\text{excess\_total} = \sum_{k \in \text{in\_scope}} \max(0,\; \text{current}[k] - \text{allowance}[k]) \le \text{policy.max\_new}$$
   - **`R-176` architecture (`rule_scope: "architecture"`):** `<base>` owns `health.architecture.modules: {<id>: {paths, area?}}` (`TN-HEALTH-PROVENANCE` on mismatch). Evaluates the single admitted report's sorted `architecture_graph: {modules, edges}` within `ci.md §5:185`'s honest limit, refusing `TN-GATE-UNKNOWN` on observable omissions only (`coverage.complete === false`, missing expected `<base>` module, or unknown edge endpoint; silent omission moves to `CP-0064`). Tarjan SCC runs in $O(\lvert V \rvert + \lvert E \rvert)$, emitting `{kind: "cyclic_edge", rule_id: "r176-cycle", from_module, to_module}` for edges inside non-trivial SCCs (`|SCC| > 1` or `u === v`) with at most 1 shortest lexicographic BFS cycle witness per SCC in `hint`.
3. **Waivers, 3-way `R-103` tamper, owners & `R-177` counters:**
   - **`accept-health-regression` (`R-203`):** Kernel `Decision` (`kind: "waive"`, `evaluation_id`, non-empty `reason`, `expiry` default `30d <= waiver_max_days`, `forge-verified` at `assure` with `person-present` optional, `1-of-N` typed `owners[].forge_accounts`, `0` verified-change credit). Rejects wrong-area (`TN-DEC-ACTOR`), expired (`TN-WAIVER-EXPIRED` at `now >= expiry`), and at `verify`/`assure` rejects author/diff-committer/`bots[]`/agent self-waive (`TN-GATE-SELF-WAIVE`); below `verify` (`observe`/`protect`), an owner self-waive is permitted labelled `self-waived`. A valid waiver binding another `evaluation_id` grants zero gate credit, stays an observation diagnostic (`TN-DEC-STALE`), and leaves the claim `status: "regressed"` (`TN-HEALTH-REGRESSED`, gate `"refuse"` / `"blocks"`).
- **Proof-card rendering & overflow (`contracts.md §5`, `ci.md §3`):** Omit the `Health:` line and all health sections completely when `health` is unconfigured. When configured, render `Health: <H> holding · <I> improved · <R> regressed · <W> waived · <U> unknown · <S> n/a` and ordered sections (`blocking_regressed` and `! Tamper watch:` essential/never cut; shed reverse order `holding` -> `improved` -> `advisory_regressed` -> `waived` -> `stale`/`config_changed`/`unknown`). Enforce `60,000` characters inclusive per head (or `Math.max(0, Math.floor((60_000 - overhead) / N))` across sorted PRs `#<n>\n` sharing a head, worst conclusion winning). On essential overflow, write full card bytes to `refs/tenet/records` at `proof/<work>/<evaluation_id>/<run_id>-<attempt>-card.md` (`overflow_ref`), keep `error.essential.slice(0, Math.max(0, budget - pointer.length))` + `"\n… (truncated at 60,000 characters · full proof card in refs/tenet/records)"`, and preserve the evaluated CI `conclusion`.
   - **3-way `R-103` tamper check:** `.tenet/health-baseline.json`, `tenet.yaml`, workflows, `CODEOWNERS`, **`.gitattributes`**, and `protect` `inputs[]` route to `protected-surfaces`; `ALG-09` weakening and suppressions matching `checks.<name>.suppression_patterns` route to `tests-not-weakened` / `health-tamper`; unattributed markers and mechanics emit `!    - **Owners & rolling `R-177` budget:** Closed owner IDs `sortAscii(unique(indicator.owner ? [indicator.owner] : check.owner ? Track rolling-30d counters deduplicated by `(work_id, indicator, fp_key)` / adjudicated `work_id` (`not_useful > 10%`, `waived`, `overrides`, `false_blocks > 2/100`) with `minimum_sample` (`20` changes / `10` findings).
