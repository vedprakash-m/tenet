## Findings

- **blocker** · `src/reports/acceptance.ts:14–17, 30–33, 39, 73, 77–84` versus `tenet/specs/plan/alpha.0.md:87` and `tenet/specs/tech-spec/contracts.md:31`. `parseAcceptance` sorts the returned `implements` and `items` arrays in place (instead of preserving first-seen document order with deduplication and sorting only inside `digest`), fails to deduplicate `implements`, collapses internal whitespace in returned `items[].text` (instead of trimming `item.text` and collapsing internal whitespace only in `digest`), and toggles code fences without matching fence character or length. **Fix:** keep first-seen document order on returned `implements` (deduped) and `items` (trimmed `text`), sort/collapse only when computing `digest`, and close fences only with a matching character of at least the opening length.
- **blocker** · `src/reports/tags.ts:21–24` and `:40–47` versus `tenet/specs/tech-spec/contracts.md:16` and `tenet/specs/tech-spec/evidence.md:53`. `extractTags` and `stripTags` use `(?:^|_)tenet_...`, which misses `tenet_AB_1` after whitespace or `>` (such as `suite > tenet_AB_1`), and `stripTags` does not clean up leading/trailing or doubled underscores when stripping `_?tenet_(?:AB|<prefix>)_\d+`. **Fix:** match `(?:^|[^A-Za-z0-9]|_)tenet_(AB|<prefix>)_(\d+)(?=$|[^A-Za-z0-9])` in `extractTags` and strip `_?tenet_(?:AB|<prefix>)_\d+` (plus trailing `_` when leading) with `__`/space cleanup in `stripTags`.
- **blocker** · `src/reports/registry.ts:88–90, 118–155, 187, 202–237, 260–263` versus `tenet/specs/tech-spec/evidence.md:24, 32, 34, 37, 38`. `parseJunit` fails to throw `TN-REPORT-MALFORMED` when both `classname` and `name` are empty, produces `"${classname} > "` instead of `classname` when `name` is empty, does not inherit `file` from ancestor `<testsuite file="…">`, and searches `<property>` via recursive `collectNodes` instead of `<testcase><properties>` only; `isTeardownError` ignores `<error>` body text when `message` is empty; `parseCtrf` checks lowercase `entry.filepath` instead of camelCase `entry.filePath`; `parseGo` drops `Elapsed` (`duration_ms`) and overwrites repeated terminal events instead of collapsing them into `attempts`; and `parseJest` maps unknown statuses to `"skip"` instead of throwing `TN-REPORT-MALFORMED`. **Fix:** implement each runner's exact `evidence.md §2` rules for JUnit empty names/suite file inheritance/pytest error body, CTRF `filePath`, Go `Elapsed` and repeated terminal `attempts`, and Jest unknown-status `TN-REPORT-MALFORMED`.
- **blocker** · `src/reports/scan.ts:175, 301–314, 383–407` and `src/reports/declared.ts:26–29` versus `tenet/specs/tech-spec/evidence.md:53–54`. `attachDescribeSources` sets `via_describe: true` even when all `describe(` tags were already present directly on the test; `braceEnd` does not ignore braces inside `//` or `/* */` comments and miscomputes `end_line` for expression-body arrow tests lacking `{...}`; and `declaredTags` checks only `added.has(sourceTag.line)`, which fails to count an inherited `via_describe` `AB-n` tag when a new inner `it(...)` declaration is added inside an unchanged `describe("[AB-1]", ...)`. **Fix:** set `via_describe` only when `describe(` adds a tag absent on the declaration, skip comments and handle expression-arrow `)` in `end_line`, and count `via_describe` `AB-n` tags when the inner declaration/title line is added in `git diff -U0`.
- **blocker** · `src/reports/weakening.ts:105–118` versus `tenet/specs/tech-spec/algorithms.md:150` (`ALG-09`). `weakening` flags `skip-added` on `//` and Python `#` comment lines and emits all enclosing declarations (e.g., outer `func TestX` plus inner `t.Run`) instead of picking only the innermost enclosing declaration (or next declaration within 3 lines). **Fix:** ignore `//` comment lines (and `#` comment lines in `.py` files) in `skip-added` and select only the innermost enclosing declaration (`largest declaration.line`) before falling back to a 3-line lookahead or trimmed line.
- **should** · `src/reports/errors.ts:12–25`, `src/reports/read.ts:19, 23, 32–36, 44, 68`, and `src/reports/acceptance.ts:54–55, 67–68` versus `tenet/specs/tech-spec/contracts.md:172` and `tenet/specs/tech-spec/messages.md:11, 18–19, 56–57`. Report errors and acceptance findings use custom wording and placeholder values (`"(empty report path)"`, `"(merged report)"`) instead of the canonical templates and `{path}` formatting rules in `messages.md`. **Fix:** format `TN-REPORT-MISSING`, `TN-REPORT-MALFORMED`, `TN-ACC-MISSING-ID`, and `TN-ACC-DUP-ID` messages and fixes using `tenet/specs/tech-spec/messages.md`.
- **should** · `test/reports/reports.test.ts:1–338` versus `tenet/specs/plan/alpha.0.md:79, 94–95`. `pkg/conformance/alg-08/cases.json` and `pkg/conformance/alg-09/cases.json` are present in the repository, but no test loads or executes them. **Fix:** add conformance test runners in `test/reports/reports.test.ts` that execute every case in `pkg/conformance/alg-08/cases.json` and `pkg/conformance/alg-09/cases.json`.
- **nit** · `src/reports/items.ts:62–64` versus `tenet/specs/tech-spec/evidence.md:55` and `tenet/specs/plan/alpha.0.md:87`. `titleMatches` strips tags via `stripTags(fullName)` with default prefix `"R"` and does not strip extra tags present only in `testCase.tags` (such as custom prefix tags or property tags that also appear in the name). **Fix:** pass `testCase` into `titleMatches` and strip any token in `testCase.tags` alongside `stripTags` before dropping a trailing `[...]` suffix.
