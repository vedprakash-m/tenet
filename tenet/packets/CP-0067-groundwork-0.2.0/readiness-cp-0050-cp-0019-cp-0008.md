## Owner decisions

D-1 · CP-0019: Which forge workflow triggers, permissions, idempotency keys and degraded results govern native review, comment reply, ready-for-review, draft conversion and close? Options: (A) define a single `pull_request_target`/`issue_comment`/`workflow_run` table with explicit permissions and add it to CI §3, or (B) keep trigger discovery inside CP-0019 and attach observed evidence afterward. Recommendation: A. CI and CP-0019 then share one auditable source and L-0030 no longer leaves the event transport open.

D-2 · CP-0008: What is the exact `flow` schema and metric window? Options: (A) define a rolling 30-day snapshot with `{value, unit, sample_size}` per metric and explicit median/p85 objects, or (B) use the whole available records history with the same typed envelope.
