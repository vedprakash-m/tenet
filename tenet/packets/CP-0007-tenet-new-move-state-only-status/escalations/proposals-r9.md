# Proposals — CP-0007 round 9

Questions from building the independent conformance suite (`pkg/conformance/events/`):

1. **`reduce(events, pack, asOf)` exact return fields:** `plan/alpha.1.md:20` specifies `{state, conflicts, findings, applied, held}` and `K §1 line 7` adds justified station and tentative moves. How are `justified_station`, `tentative_moves` (including the pending-deadline transition to `unjustified`, `K §1 line 34`), and non-`TN-*` structural findings (`cycle`, `cross-work-predecessor`, `missing-creation`, `multiple-creations`) represented on the returned object?
2. **`readProofRecord(path, bytes)` return type and unsupported version error:** `plan/alpha.1.md:20–22` and `K §2 line 42` require read-only compatibility across alpha.0 `proof/<work>/<eval>/<run>-<attempt>.json`, `latest` pointers, and `rules/<yyyy-mm>.jsonl`, plus failing on an unsupported legacy/future `schema_version`. What exact tagged union `{kind, schema_version, data, unknown_fields}` should `readProofRecord` return, and should an unsupported `schema_version` emit `TN-SCHEMA` or a distinct finding/error?
3. **`recordForgeEvent(input)` event mapping and stale delivery:** `plan/alpha.1.md:21` requires recording `ready`, `draft`, `merged`, and `unmerged closed` observations using the stable delivery/resource identity from `CP-0040`'s event table (`L-0030 line 42`), and rejecting/ignoring stale forge events (`line 22`). What exact `event.data` shape identifies forge provenance (delivery ID, resource URL, action, head SHA, signed/unsigned marker), and does a stale forge event (older timestamp or non-current head SHA) return `{recorded: false, reason}` vs emitting a note event?
4. **Aliases and advisory leases (`aliases.ts`, `leases.ts`):** `plan/alpha.1.md:19, 21` and `Contracts §1 line 13` specify `CP-<6 Crockford Base32>` alias lengthening on collision and advisory working-copy `lease.*` events (`TS §5 line 119`). Are alias helpers exported as `deriveAlias(ulid, existingAliases)` (starting at length 6, lowercase/uppercase exact Crockford alphabet), and how do `leases.ts` helpers report overlapping `paths` or expired leases on `reduce` / CLI?
5. **Unresolved `resolve` and missing-head edge cases:** When a `decision.made` (`resolve`) event names only a subset of active conflict heads in `prev` (`K §1 line 21`, `ALG-05 line 87`), is the partial resolution ignored/held with a structural finding while the conflict stays open?
