## 1. Problem and outcome

Code health keeps software changeable (`V-V10`, `V-P9`) while legacy debt never blocks unrelated edits (`V-M10`). Whole-repo thresholds stall work, offline bug lists see ~0% fix rates at Meta vs ~70% for diff-time review comments, noisy checks trigger workarounds, and benchmark stress tests measure agents gaming visible checks they can edit (30.4% in METR RE-Bench; 49%–76% in ImpossibleBench), motivating protected inputs and verifiable evidence rather than predicting Tenet's own rates.

**Outcome:** record existing debt per `(area, indicator)` as a protected floor, enforce only trusted, non-self-reported checks on `area`/`touched` scope beyond exact policy tolerance, tighten monotonically from `main`, mint fresh evaluations on baseline/exception shifts, trigger pre-merge re-evaluation atomically (`CP-0035`), attribute architecture and durability deterministically, and track noise over stable change identities without slowing `quick` work.

## 3. Design

### 3.1 Per-key baseline store, signed precedence, CAS & merge eligibility (GPT F1, MAI F4)

1. **Keyed schema (`kit/schemas/health-baseline.json`):** `{schema_version: 1, entries: {"<area>::<indicator>": BaselineEntry}}`. Each `BaselineEntry` stores `{area, indicator, kind: "scalar"|"finding_set", tool, tool_version, config_digest, scope_digest, reset_seq: int>=0, main_seq: int>=0, main_commit, run_id, run_attempt, value?: number, numerator?: int, denominator?: int, allowed_counts?: Record<fp_key, int>=0}`.
2. **Initialization, two stores & signed crash recovery:**
   - **Committed floor (`.tenet/health-baseline.json`, `protect` -> `change-policy`):** holds initial adoption (`origin: observed`, `reset_seq: 0`) and deliberate per-`(area, indicator)` resets (`reset_seq += 1` or changed `config_digest` / `scope_digest` on targeted keys ONLY; sibling keys stay intact). An enabled indicator missing from **both** committed floor and `records` fails `TN-HEALTH-BASELINE` (`unknown` below `verify`, `failure` at `verify`/`assure`, never silent empty pass).
   - **Signed-first `attest` write order (`refs/tenet/evidence` -> `refs/tenet/records`):** At `verify`/`assure`, `attest` writes immutable signed `<main_commit>/health-baseline-<sha256>.json` to `refs/tenet/evidence` **first**, then CAS-updates mutable `refs/tenet/records: health/baseline.json` + `health/baseline.latest` (`{sha256, main_seq, main_commit}`). If interrupted between evidence write and pointer commit, retry recovers `health/baseline.json` forward from the signed snapshot matching `main_commit`; if mutable `records` fails SHA-256 verification against `refs/tenet/evidence` at `verify`/`assure`, refuse (`TN-HEALTH-BASELINE` / `unsigned`).
3. **Per-`(area, indicator)` effective baseline (given target `<base>`):**
   - If `committed.reset_seq > records.reset_seq` OR (`committed.config_digest !== records.config_digest` / `committed.scope_digest !== records.scope_digest` matching `<base>`): `committed` wins (`reset`). If `committed.reset_seq < records.reset_seq`: refuse `TN-HEALTH-BASELINE`.
   - At equal `reset_seq`, `config_digest`, and `scope_digest`: `scalar` uses strictly tighter value (`max` `"up"`, `min` `"down"`); `finding_set` uses **element-wise `min`** (`effective[k] = min(committed[k] ?? 0, records[k] ?? 0)`), rejecting any `records[k] > (committed[k] ?? 0)` (`TN-HEALTH-BASELINE`).
4. **Universal `canTighten` pre-gate & CAS race arbitration (GPT F1):**
   Before evaluating ANY write branch `(i)–(iv)` on `main`, an `(area, indicator)` run MUST satisfy **all** of: `exit_code === 0`, `complete === true`, `coverage_verified === true`, `provenance_ok === true`, full-area coverage (`scalar.population === "area"`, OR `finding_set` covering 100% of `<base>` `expected_paths` / `expected_modules` under `"target-files" | "target-modules"` — PR subset runs NEVER tighten!), matching `(tool, tool_version, config_digest, scope_digest)`, and no active unrecovered `accept-health-regression` on `(area, indicator)`. Any failure exits cleanly without modifying `health/baseline.json`. Inside the 8-retry CAS loop (`ci.md §4`), check tip `(base_reset_seq, base_config_digest, base_scope_digest)` match (`reset_seq` race guard), then:
   - (i) `main_commit === tip.main_commit` (retry): tighten only if `(run_id, run_attempt)` is newer, never loosening;
   - (ii) `isFirstParentAncestor(main_commit, tip.main_commit)`: ignore stale run;
   - (iii) neither is first-parent ancestor (`main` rewrite): refuse update (`TN-HEALTH-BASELINE`) until committed `reset_seq` bump;
   - (iv) `isFirstParentAncestor(tip.main_commit, main_commit)` (or initial entry from committed): tighten monotonically and increment `main_seq`.
5. **Evaluation ID binding & atomic integration-time refresh (GPT F1, MAI F4):**
   - Extend `contracts.md:18` `evaluation_id` input (for `0.1.x`) with **`health_basis_digest = sha256(RFC 8785 {effective_baselines, active_exceptions})`** covering all applicable `(area, indicator)` entries. Any `main` baseline tightening or exception state change mints a new `evaluation_id` (`R-090`), preserving historical replay of prior IDs while invalidating old approvals/statuses as current merge authority!
   - **Atomic integration trigger (`tenet.yml` + `CP-0035`):** `tenet.yml` adds `push` (default branch sweep updating open PR statuses when `health/baseline.json` tightens), `pull_request_target: [synchronize, edited, ready_for_review]`, periodic `schedule` expiry sweep, and `merge_group: [checks_requested]` (`CP-0035`, required dependency in `packet.yaml`). Merge-time gate evaluates the exact candidate against `<base>`, live signed `health/baseline.json`, active exceptions, and injected `now`, **failing closed** if status refresh is unavailable or marks **`stale-baseline` / `TN-WAIVER-EXPIRED`**.

### 3.2 Indicator kinds, exact arithmetic, population hash & `R-176` graph (GPT F3, F4, F5)

1. **`scalar` (`health.indicators.<name>`):** `{kind: "scalar", population: "area" | "touched" | "sampled_runs", comparison: "area_baseline" | "paired_touched" | "sampled_window", unit, direction: "up" | "down", tolerance: {kind: "absolute" | "relative-pct", value >= 0}, min_samples?, low_sample_under?: 20}`.
   - **Enforcement & `scope_digest` (`GPT F5`):** ONLY `population: "area"` (`area_baseline`) may be `enforce` or tighten `main`; `touched` and `sampled_runs` carry `metric_cap = "advise"` (zero lane credit). For `area`, **`scope_digest = sha256(RFC 8785 {kind: "area", area, area_paths: sorted(effective_area_paths), area_source_digest, scope_globs: sorted(scope_globs), exclude_globs: sorted(exclude_globs), unit})`** — catching any `area.paths`, `CODEOWNERS`, `scope_globs`, or `exclude_globs` change without hashing individual tracked filenames.
   - **Exact comparison (rounding display-only):** Use cross-multiplied `BigInt` over `(numerator, denominator)` rationals (or exact decimal scaled `BigInt` for float-only finite values; `NaN`/`Infinity` -> `TN-REPORT-MALFORMED`). Boundary equality passes; `relative-pct` at `baseline === 0` allows `0` slack; `denominator === 0` yields `not-applicable` iff `expected_paths.length === 0`, else `TN-GATE-UNKNOWN`.
2. **`finding_set`:** `{kind: "finding_set", scope: "touched_lines" | "touched_files" | "area", max_new: int >= 0, rule_scope: "lint" | "type" | "complexity" | "architecture" | "docs"}`. `fp_key = sha256(RFC 8785 {rule_id, file, symbol: symbol ?? "", snippet_hash})`. Mismatched config/unit/scope emits `TN-HEALTH-INCOMPATIBLE` / `TN-HEALTH-CONFIG-CHANGED`; `records` resolved below committed floor emits `TN-HEALTH-STALE` (`advise`).
3. **`R-176` architecture rules (`rule_scope: "architecture"`, GPT F4):**
   - **Target-owned module map (`tenet.yaml`):** `health.architecture.modules: {<module_id>: {paths: [glob], area?: <area_id>}}` lives in `<base>` `tenet.yaml` (missing map emits `TN-GATE-UNKNOWN`; report module definitions conflicting with `<base>` fail `TN-HEALTH-PROVENANCE`).
   - **Required `architecture_graph` payload:** A `rule_scope: "architecture"` `HealthEntry` MUST carry **`architecture_graph: {modules: [module_id], edges: [{from_module, to_module, from_file?, to_file?}]}`** (complete sorted directed edge set including **acyclic** edges!) alongside rule violations (`forbidden_import`, `layer_violation`) in `findings[]`.
   - **Deterministic $O(|V|+|E|)$ Tarjan SCC evaluator:** Confirm `expected_modules ⊆ coverage.analyzed_modules` (`TN-GATE-UNKNOWN` otherwise). Derive cyclic directed edges `(u -> v)` where `SCC(u) === SCC(v)` and `(|SCC(u)| > 1 || u === v)`, keyed `sha256(RFC 8785 {kind: "cyclic_edge", rule_id: "r176-cycle", from_module: u, to_module: v})`. **Bounded display witnesses:** compute **at most ONE shortest lexicographic BFS cycle witness per cyclic SCC** (capped at `20` hops, up to `10` SCC witnesses per card) — keeping graph evaluation strictly $O(|V|+|E|)$. Map `from_file` / `health.architecture.modules[u].paths` + `modules[v].paths` to `areas` (`TN-GATE-UNKNOWN` if unmapped).

### 3.3 Shared `ALG-15` diff mapper & storage-free touched scope rules (MAI F1, GPT F3, F4)

1. **`src/specs/diff-mapper.ts` (`ALG-15`):** Replaces **BOTH** `src/specs/touched.ts:88,112-178` **and** `src/reports/weakening.ts:164-230` (deleting duplicated `fileChanges` & `diffLines` in both) as the sole raw diff parser for `ALG-08`, `ALG-09`, `ALG-14`, `CP-0036`, and `CP-0039`.
   - Pinned invocation: `git -c core.quotepath=false -c diff.algorithm=myers -c diff.renames=true -c diff.renameLimit=1000 -c diff.mnemonicPrefix=false -c diff.noprefix=false -c diff.relative=false diff --no-ext-diff --no-textconv --no-color -M50%` (`--name-status -z` + `--unified=0 --no-prefix`), decoding NUL-delimited UTF-8 / C-octal escapes, POSIX `/`, `Buffer.compare` ordering. Rename-limit overflow (`stderr` matches `rename detection|renameLimit` or `> 1000` `A`/`D` candidates) returns `{status: "unknown", reason: "rename-limit-exceeded"}`.
2. **Diff operands:** Record `base_sha`, `head_sha`, `tested_sha`, and **`diff_base_sha = git merge-base base_sha tested_sha`** (fail `unknown` if disjoint), isolating PR diffs from advanced target commits.
3. **Explicit `finding_set` scope & trade-off rules (GPT F3 — no stored line locations required):**
   - Zero `min_changed_lines` skip on enforced `R-175`; advisory ratios attach `low_sample: true` below `low_sample_under` (`20`).
   - **`touched_lines` (storage-free strict hunk contract):** Evaluate every finding whose `[line, end_line]` overlaps a new-side added/modified hunk **directly (`0` baseline subtraction inside touched hunks)** plus any finding whose `referenced_paths[]` hits a deleted/modified/renamed `old_path` where `!baseline.allowed_counts[fp_key]`. *Documented trade-off:* unmodified shifted lines pass cleanly outside `-U0` hunks (`0` churn), deleting in hunk A + adding in hunk B is always caught (`+1`, zero cross-hunk credit), and editing a pre-existing violating line re-enters review scope unless switched to `touched_files`. Findings in `touched_lines` lacking both `line` and `referenced_paths[]` fail `TN-HEALTH-INCOMPATIBLE`.
   - **`touched_files` (per-file count-only contract):** Compare multiset counts strictly per **`(file_or_renamed_path, area, fp_key)`** against `baseline.allowed_counts`. `-M50%` renames carry baseline credit **iff `area(old_path) === area(new_path)`** (zero cross-area credit transfer). *Trade-off:* deleting + adding identical `fp_key` within the same file nets `0`, while adding without deleting or crossing files/areas flags `+1`.
   - **`area`:** Compare whole-area `current[fp_key]` against `baseline.allowed_counts[fp_key]` (shrink-only on `main`).

### 3.4 Secondary health reports, trusted runner receipts, SARIF/matrix parity & `ALG-06` (MAI F2, F3; GPT F2, F5, F6, F8, F9)

1. **`checks.<name>.health_reports` & `VerifyDeps` (`kit/schemas/tenet-yaml.json`, `bundle.json`, MAI F2):**
   - A health producer is **either** (a) a standalone check `checks.<name>` with `report: tenet-health-json | sarif | lcov | cobertura`, **or** (b) a test/build check declaring optional **`checks.<name>.health_reports: [{id, format: tenet-health-json|sarif|lcov|cobertura, report_path, indicators: [string], required?: bool}]`** (`report_path` confined `.tenet/reports/...`, distinct from primary `report_path`; duplicate `id` fails `TN-POLICY-SCHEMA`; in `indicators.<name>`, `report_id?` binds to one specific secondary slot when `checks.<name>` declares `health_reports`).
   - `bundle.checks[]` adds `{format?, health_reports?: [{id, format, report, report_sha256, runner_receipt}]}`. Missing `required !== false` secondary report emits `TN-REPORT-MISSING`; missing optional secondary report emits `unknown` advisory; an unreferenced file in `health_reports` missing from `<base>` policy fails `TN-HEALTH-PROVENANCE`.
   - **`VerifyDeps.readHealth(format, content, context)` & `readHealthEvidence(bundles, policy, proposed?)` (`src/verify/record.ts`):** receives `{check, report_id, tested, base, indicators_by_area, expected_scope, modules_map, receipt}` and outputs canonical `health-input.json` (assigning policy `area` & `indicator` when SARIF/LCOV/Cobertura lack them; throwing `TN-REPORT-MALFORMED` if a report supplies `tolerance`/`max_new`/`mode`/`waived`).
2. **Producer trust boundary & `runner_receipt` (`GPT F2`, `MAI F3`):**
   - Separate **`scope_source`** cleanly in the runner's trusted receipt (`runner_receipt = {producer_kind: "built-in-verifier" | "runner-supervised" | "self-declared", executable_sha256, package_integrity, effective_command, config_sha256, pinned_inputs_digest, actual_analyzed_paths: [string], actual_analyzed_modules?: [string]}`):
     - **`"built-in-verifier"` / `"runner-supervised"`:** protected runner/verifier (reference producer: package-locked Tenet built-in TS/ESM import-graph & doc-link analyzer under `@vedprakash-m/tenet@<locked>`, or runner directly spawning pinned binary with explicit `--files <expected_paths>` & `<base>` config without project build hooks) independently enumerates `expected_paths` from `<base>` `tenet.yaml`, verifies pre/post tracked files unchanged (`TN-SEALED-DIRTY`, `ci.md §5:176`), and writes `actual_analyzed_paths` into `runner_receipt`. **ONLY** this path with `expected_paths ⊆ runner_receipt.actual_analyzed_paths` sets `coverage_verified = true` (`enforce` & `main` tightening eligible).
     - **`"self-declared"`:** subject-executed scripts, generic external `tenet-health-json`, or SARIF/LCOV/Cobertura lacking runner file-scope supervision carry `coverage_verified = false` (**`coverage_unverified`** — **never** elevated to `enforce` or `main` tightening even if the report JSON asserts `complete: true` and lists all `expected_paths`!). Binding an `enforce` indicator to a `"self-declared"` producer fails `tenet check` / `verify` (`TN-HEALTH-PROVENANCE`).
3. **Matrix, multi-run SARIF & adapter normalization (`GPT F8`):**
   - Each `(area, indicator)` binds **one authoritative producer `(check, report_id?, shard_mode)`** in `<base>` `tenet.yaml` (`shard_mode: "single" | "matrix-agree" | "matrix-distinct"`, default `"single"`). Identical canonical bytes collapse idempotently; `"single"` refuses multiple differing shard payloads (`TN-HEALTH-INCOMPATIBLE`); `"matrix-agree"` requires all expected shards complete & identical (except `sampled_runs` aggregating `samples`); `"matrix-distinct"` requires disjoint shard `scope_globs` whose union covers `expected_paths` (overlapping LCOV/Cobertura summation strictly forbidden).
   - **Multi-run SARIF:** Iterate **ALL** `sarif.runs[]` (`runs.length === 0` -> `TN-REPORT-MALFORMED`); any run with `invocations` failure sets `complete: false`; heterogeneous driver mismatch vs pinned tool -> `TN-HEALTH-PROVENANCE`. LCOV & Cobertura normalize equivalent `{area, numerator, denominator, analyzed_paths}` to byte-identical `health-input.json`.
4. **Precedence, `ALG-06` freeze & `ci.md §10` outcomes (`GPT F5`, `F6`):**
   - Inherited `ALG-06` indicators **never** narrow `scope_globs` or add `exclude_globs` (`TN-POLICY-LOOSEN` on any exclusion addition or prefix narrowing; narrower scopes must declare an independent child indicator leaving the parent intact!).
   - Optional (`observe`/`advise`) missing/`coverage_unverified`/`unknown` indicators emit diagnostic `unknown` without failing `verify`; `enforce` indicators missing/`coverage_unverified`/`TN-HEALTH-PROVENANCE` fail `verify` and never tighten `main`.
5. **Tool-neutral `R-103` tamper routing (`GPT F9`):**
   - (1) Trust surfaces (`.tenet/health-baseline.json`, `tenet.yaml`, workflows, `CODEOWNERS`, `protect` `inputs[]`) -> `protected-surfaces` (`change-policy`); (2) Attributed weakening (`ALG-09` test weakening OR added comment-anchored suppression matching an active pinned check/indicator's `suppression_patterns` in its `scope_globs`, OR explicitly configured `protect` suppression patterns) -> `tests-not-weakened` / `health-tamper`; (3) Unattributed suppression markers, non-`protect` configs, clean new tests -> diagnostic `! Tamper watch:` (`R-103` normal review, zero `quick` gate).

### 3.5 Typed owners, replayable exceptions (`R-143`) & gap-aware `R-178` durability (MAI F3, F5; GPT F6, F7)

1. **Typed owner quorum (`owners[].id`):** `allowed = indicator.owner ? [indicator.owner] : check.owner ? 2. **Replayable exceptions & `R-143` (`GPT F6`):**
   - Derive active exception state strictly from attested immutable records (`work.integrated` + binding `Decision` with Kernel **`expiry`** + `(baseline_digest_at_waive, reset_seq_at_waive, policy_revision, evaluation_id)`). Each `exception_id` clears **only** via an immutable `health.exception.recovered` observation on `main` (`exit_code === 0, complete, coverage_verified, same reset_seq`) meeting `baseline_digest_at_waive`, OR a committed `reset_seq > reset_seq_at_waive` (`change-policy` `decision_id`). Missing/corrupted exception/recovery records force `area` health **`unknown` (`declined` at `verify`/`assure`, never silent reopen)**. Once `now >= Decision.expiry` on any unrecovered exception, `area` becomes `declined` (`expired-waiver`), blocking new `express`/`quick` intake & next gates (`R-143`); live open-PR gate flips `waived -> TN-WAIVER-EXPIRED` via §3.1.5 trigger.
3. **Authoritative gap-aware `R-178` durability joining `CP-0037` (`ALG-17`, GPT F7, MAI F5):**
   - **Dependency & stream:** Requires **`CP-0037`** (`packet.yaml`: join `{work_id, integration_commit, authored_by, agent_definition, work_type}`; `unknown` ONLY when `CP-0037` record absent/incomplete). Commit chain uses `git log --first-parent <main>` `M^1..M` (`ALG-15`; excludes closed-without-merge `work.closed`). **`M.integrated_at`** comes from immutable `work.integrated` / default-branch push receipt `recorded_at`, else monotonic Git committer timestamp (`%cI`, `"git-committer"`).
   - **Dated daily buckets & gap-aware checkpoint (`refs/tenet/records: health/durability-state.json`):** Store `buckets[UTC_YYYY_MM_DD][agent_definition][work_type] = {cohort_commits, lines_added, lines_rewritten_or_reverted_30d}` + `{processed_head, pending_gaps: [{commit, reason: "budget-stop"|"oversize-commit"}]}` so cohorts age out of `[as_of - 60d, as_of - 30d]` identically in incremental and full-history runs! Bounded per async `main` run (`250` commits / `50 MB` / `60s`): budget stops pause `processed_head` for exact catch-up; permanent `> 20,000`-line oversize commits still scan touched paths for rewrites to earlier open lines, omit their own added lines, and surface `{status: "partial-gap", coverage_pct, pending_gaps}` (`shallow-history` also emits `incomplete`). Pure `-M50%` renames preserve surviving lines (`0` rewrite); `lines_added === 0 -> durability_rate: null`.
