# CP-0039 definition · Health indicators and ratchet

> Shape round 3 (v3 changelog: resolved GPT R2 F1–F10 & MAI R2 F1–F4; see [response-r2.md](escalations/response-r2.md)) · Implements `R-175`–`R-178` · Sources: [research-code-health.md](evidence/research-code-health.md), [review-r1-gpt.md](escalations/review-r1-gpt.md), [review-r2-gpt.md](escalations/review-r2-gpt.md), [review-r2-mai.md](escalations/review-r2-mai.md), [L-0038](../../ledger/L-0038-review-rounds-and-public-home.md), [plan/0.1.x.md](../../specs/plan/0.1.x.md).

## 1. Problem and outcome

Code health keeps software changeable (`V-V10`, `V-P9`) while legacy debt never blocks unrelated edits (`V-M10`). Whole-repo thresholds stall work, offline bug lists see ~0% fix rates at Meta vs ~70% for diff-time review comments, noisy checks trigger workarounds, and benchmark stress tests measure agents gaming visible checks they can edit (30.4% in METR RE-Bench; 49%–76% in ImpossibleBench), motivating protected inputs and verifiable evidence rather than predicting Tenet's own rates.

**Outcome:** record existing debt per `(area, indicator)` as a protected floor, block only unwaived regressions beyond exact policy tolerance on touched/area scope, tighten monotonically from `main`, render actionable proof cards, prove check coverage and inputs against tampering, attribute architecture rules and 30-day durability cleanly, and track noise separately without slowing `quick` changes.

## 3. Design

### 3.1 Per-key baseline store, signed precedence, CAS & merge eligibility (GPT F1)

1. **Keyed schema (`kit/schemas/health-baseline.json`):** `{schema_version: 1, entries: {"<area>::<indicator>": BaselineEntry}}`. Each `BaselineEntry` stores `{area, indicator, kind: "scalar"|"finding_set", tool, tool_version, config_digest, scope_digest, reset_seq: int>=0, main_seq: int>=0, main_commit, run_id, run_attempt, value?: number, numerator?: int, denominator?: int, allowed_counts?: Record<fp_key, int>=0}`.
2. **Two stores + signed attestation copy:**
   - **Committed floor (`.tenet/health-baseline.json`, `protect` -> `change-policy`):** holds initial adoption (`origin: observed`) and deliberate per-`(area, indicator)` resets (bumping `reset_seq += 1` or changing `config_digest` on targeted keys ONLY; sibling keys stay intact).
   - **Mutable pointer (`refs/tenet/records: health/baseline.json`) & signed snapshot (`refs/tenet/evidence: <main_commit>/health-baseline-<sha256>.json`):** written only by the `main` recorder/attest job via git plumbing CAS (`ci.md §4–§5`). At `verify`/`assure`, evaluator checks `health/baseline.json` SHA-256 against the latest signed `refs/tenet/evidence` snapshot (`unsigned` / `TN-HEALTH-BASELINE` refusal on mismatch). Below `verify`, `records` acts as an observed/detected overlay.
3. **Per-`(area, indicator)` effective baseline (given target `<base>`):**
   - If `committed.reset_seq > records.reset_seq` OR (`committed.config_digest !== records.config_digest` while `committed` matches `<base>` policy): `committed` wins (`reset`).
   - If `committed.reset_seq < records.reset_seq`: refuse `TN-HEALTH-BASELINE`.
   - At equal `reset_seq` and matching `(tool, tool_version, config_digest, scope_digest)`:
     - **`scalar`:** strictly tighter value (`max` for `direction: "up"`, `min` for `"down"`).
     - **`finding_set`:** **`records` may ONLY shrink counts relative to `committed`** (`element-wise min`: for every `fp_key`, `effective[k] = min(committed[k] ?? 0, records[k] ?? 0)`). If any `records[k] > (committed[k] ?? 0)`, reject overlay (`TN-HEALTH-BASELINE`) — eliminating incomparable multisets.
4. **`main` monotonic CAS & race arbitration:** Recorder runs `main` tightening inside an 8-retry jittered CAS loop (`ci.md §4`), evaluating each `(area, indicator)` independently against tip `health/baseline.json`:
   - Require `tip.reset_seq === run.base_reset_seq` and `tip.config_digest === run.base_config_digest` (rejects pre-reset runs racing a reset).
   - Commit ordering: (i) if `main_commit === tip.main_commit` (same-commit retry): tighten `element-wise`/scalar only when `run_id`/`run_attempt` is newer, never loosening; (ii) if `isFirstParentAncestor(main_commit, tip.main_commit)`: ignore older commit; (iii) if neither is first-parent ancestor of the other (`main` rewritten): refuse update (`TN-HEALTH-BASELINE`) until a committed `reset_seq` bump restores lineage; (iv) if `isFirstParentAncestor(tip.main_commit, main_commit)` (or initial) AND `exit_code === 0`, `complete === true` covering 100% of `expected_scope`, `population === "area"` (never `touched`/`sampled_runs`), and no unrecovered `accept-health-regression` on `(area, indicator)`: tighten monotonically and increment `main_seq`.
5. **In-flight PR replay vs. merge eligibility (`kernel §1–§2`, `R-090`):** Historical replay of evaluation `E` keeps `E`'s pinned `(base_commit, baseline_digest)`. At `integrate` / live merge gate (`verify`/`assure`), compare `E`'s per-key effective baseline digests (for enforced touched indicators) against **current target `<base>`** effective baseline; any change marks `E` **`stale-baseline`** (`unsatisfied` / `ci/wait-for-evidence` re-evaluation required against current target, preserving historical logs).

### 3.2 Indicator kinds, exact arithmetic & `R-176` graph unit (GPT F3, F5)

1. **`scalar` (`health.indicators.<name>`):** `{kind: "scalar", population: "area" | "touched" | "sampled_runs", unit, direction: "up" | "down", comparison: "area_baseline" | "paired_touched" | "sampled_window", tolerance: {kind: "absolute" | "relative-pct", value >= 0}, min_samples?, low_sample_under?: 20}`.
   - **Enforcement boundary:** ONLY `population: "area"` (`comparison: "area_baseline"`) is eligible for `enforce` and `main` tightening (`scope_digest = sha256(RFC 8785 {kind: "area", area, scope_globs, exclude_globs, unit})`, invariant to adding/removing files). Both `touched` (`paired_touched` recomputed over `diff_base_sha..tested_sha` with matching `scope_digest`) and `sampled_runs` (`sampled_window`, visible `quarantined` count) carry `metric_cap = "advise"` with zero `enforce` lane credit (`0`-cumulative-drift guarantee).
   - **Exact comparison (display rounding never alters verdicts):** When integer `numerator`/`denominator` exist, evaluate cross-multiplied `BigInt` inequalities against rational baseline and exact decimal tolerance; for finite float-only inputs, parse exact decimal scaled `BigInt` (`NaN`/`Infinity` -> `TN-REPORT-MALFORMED`). Boundary equality passes; `relative-pct` at `baseline === 0` gives `0` slack. `denominator === 0` yields `not-applicable` iff `expected_paths.length === 0`, else `TN-GATE-UNKNOWN`.
2. **`finding_set`:** `{kind: "finding_set", scope: "touched_lines" | "touched_files" | "area", max_new: int >= 0, rule_scope: "lint" | "type" | "complexity" | "architecture" | "docs"}`. Fingerprint `fp_key = sha256(RFC 8785 {rule_id, file, symbol: symbol ?? "", snippet_hash})` (`CRLF->LF`, collapsed horizontal whitespace). Mismatched `unit`/`direction`/`population`/`scope_digest` emits `TN-HEALTH-INCOMPATIBLE`; `(tool, tool_version, config_digest)` drift emits `TN-HEALTH-CONFIG-CHANGED`; `records` counts resolved on `main` vs stale committed floor emits `TN-HEALTH-STALE` (`advise`).
3. **`R-176` architecture rules (`rule_scope: "architecture"`, GPT F5):** Report MUST carry `modules: [{id, root_globs: [glob]}]`, full directed edges, and `analyzed_modules`:
   - **Edge violations (`forbidden_import`, `layer_violation`):** key = `sha256(RFC 8785 {kind: "edge", rule_id, from_module, to_module})`, `hint` non-empty (`evidence.md:11`).
   - **Cycles (Tarjan SCC bounded unit, $O(\lvert V \rvert+\lvert E \rvert)$):** Compute SCCs on the directed module graph; every edge `(u -> v)` where `SCC(u) === SCC(v)` and `(|SCC(u)| > 1 || u === v)` emits key = `sha256(RFC 8785 {kind: "cyclic_edge", rule_id, from_module: u, to_module: v})`. Attach a shortest lexicographic BFS cycle witness in `hint` (`display-only`, omitted from `fp_key`). Every equivalent cycle enumeration produces identical keys while any new cyclic edge triggers a distinct violation. Attribute affected areas via `from_file` (edges) and `modules[u].root_globs ∪ modules[v].root_globs`; unmapped or missing `analyzed_modules` emits `TN-GATE-UNKNOWN`.

### 3.3 Shared `ALG-15` diff mapper & touched attribution (MAI F1, GPT F4)

1. **`src/specs/diff-mapper.ts` (`ALG-15`, replaces `src/specs/touched.ts:88,112-178` for `ALG-08/09/14`, `CP-0036`, `CP-0039`):**
   - Pinned git options: `git -c core.quotepath=false -c diff.algorithm=myers -c diff.renames=true -c diff.renameLimit=1000 -c diff.mnemonicPrefix=false -c diff.noprefix=false -c diff.relative=false diff --no-ext-diff --no-textconv --no-color -M50%` (running `--name-status -z` + `--unified=0 --no-prefix`), decoding NUL-delimited UTF-8 / C-escaped octal paths, POSIX `/`, `Buffer.compare` ordering.
   - If git reports rename-limit overflow (`stderr` matches `rename detection|renameLimit` or >`1000` `A`/`D` candidates), return `{status: "unknown", reason: "rename-limit-exceeded"}` rather than partial/OS-dependent pairing.
2. **Pinned diff operands:** Record `base_sha`, `head_sha`, `tested_sha` (merge candidate else `head_sha`), and **`diff_base_sha = git merge-base base_sha tested_sha`** (or fail `unknown` if no common ancestor). PR diff always uses `diff_base_sha..tested_sha` so advanced target commits never leak into PR scope.
3. **Scope attribution & credit rules (no 20-line bypass):**
   - Zero `min_changed_lines` skip on enforced `R-175`; advisory ratios attach `low_sample: true` when lines `< low_sample_under` (`20`).
   - **`touched_lines`:** Only findings whose `[line, end_line]` overlaps a new-side added/modified hunk **OR** whose `referenced_paths[]` matches a deleted/modified/renamed `old_path` enter scope (if a `touched_lines` indicator emits findings lacking both `line` and `referenced_paths[]`, refuse `TN-HEALTH-INCOMPATIBLE`). Credit from baseline applies **1:1 only inside the exact paired replacement hunk** (`oldStart..oldEnd`) for identical `(rule_id, file, symbol, snippet_hash)`. Deleting a finding in hunk A and adding an identical finding in hunk B gets **0 credit (`+1` new)**. Unmodified shifted lines fall outside all added hunks (`0` false positives).
   - **`touched_files`:** Evaluates multiset counts strictly within `(file_or_renamed_path, fp_key)` — never netting across distinct files. Pure `-M50%` renames carry `1:1` credit **iff `area(old_path) === area(new_path)`**; cross-area renames transfer **0 credit** (`+1` in new area).

2. **Field-by-field adapter normalization into canonical `health-input.json` (sorted, LF, identical bytes across equal reports):**

3. **Provenance & independent completeness (`ci.md §5`, GPT F2):**
   - `verify` computes `expected_paths` (`area.paths ∩ scope_globs \ exclude_globs` on `<tested>`) and `expected_modules` independently from `<base>` `tenet.yaml`.
   - Test job records `pinned_inputs_digest = sha256(RFC 8785 {run, env_allowlist, inputs: sorted({path, sha256})}, tool_version_output)` before execution and verifies tracked files unchanged afterwards (`TN-SEALED-DIRTY`, `ci.md §5:176`). `attest` independently verifies `<base>` config digests and `tested_commit`.
   - `complete === true` requires **both** clean tool completion AND **`expected_paths ⊆ analyzed_paths`** (or `expected_modules ⊆ analyzed_modules` for `R-176`). Reports omitting `analyzed_paths`/`analyzed_modules` are tagged **`coverage_unverified`** (`observe`/`advise` diagnostic only, never `enforce` or `main` tightening).
4. **Mode precedence & aligned `ci.md §10` outcomes (GPT F6):**
   - **Policy owns all thresholds/modes** in `<base>` `tenet.yaml`; PR proposals to add/promote an indicator run at `observe` (`proposed`) below `verify` and fail `TN-POLICY-RULE-DECISION` (`change-policy`) at `verify`/`assure`.
   - `effective_mode = min(rules["health-ratchet"], indicator.mode ?? "observe", metric_cap)` (`touched` and `sampled_runs` have `metric_cap = "advise"`).
   - **Cross-layer `ALG-06` compatibility:** Changing `kind`, `unit`, `direction`, `population`, `comparison`, `scope`, `check`, `tolerance.kind`, or dropping an inherited indicator -> `TN-POLICY-INCOMPATIBLE`; raising `tolerance`/`max_new`, lowering `min_samples`, weakening `mode`, or diverging `scope_globs` beyond literal path-prefix specialization -> `TN-POLICY-LOOSEN`.

| Situation | Optional (`observe` / `advise`) Indicator | Mandatory (`enforce`) Indicator | `main` Tightens? |
|---|---|---|---|
| Complete, valid, provenance OK | `holding` / `improved` / `advisory-regressed` | `holding` / `improved` / **`failure`** (`TN-HEALTH-REGRESSION`) | Yes (unwaived `area`) |
| Missing/malformed/truncated/`coverage_unverified`/`TN-GATE-UNKNOWN` | `unknown` (advisory `"not checked"`, CI stays green/neutral) | **`failure`** at `verify`/`assure` (`advisory` below `verify`) | Never |
| Wrong commit / `inputs_digest` mismatch / unsigned evidence | `inadmissible` (advisory `"untrusted input"`) | **`failure`** (`TN-HEALTH-PROVENANCE`) at `verify`/`assure` | Never |
| Non-zero `exit_code` (even with passing report) | `failed` (advisory unless in `lane_checks`) | **`failure`** | Never |

5. **3-way `R-103` tamper routing (GPT F9 — routine `quick` work unblocked):**
   - **Trust surfaces:** edits to `.tenet/health-baseline.json`, `tenet.yaml`, workflows, `CODEOWNERS`, `protect` `inputs[]` -> `protected-surfaces` (`change-policy`).
   - **Established weakening:** `ALG-09` test weakening (`removed-tests`, `skip-added`, `file-deleted`) OR added comment-anchored suppression directives (`//\s*(eslint-disable|biome-ignore|@ts-(expect-error|ignore)|nolint)`, `^\s*#\s*noqa\b`, `#\[allow\(`, excluding string literals) -> **`tests-not-weakened` / `health-tamper`** (enforced per `protect`/`verify` even when `health-ratchet` is `observe`).
   - **Mechanics (diagnostic only):** non-`protect` config edits (`package.json`, `tsconfig.json`, `biome.json`, etc.) and clean new tests -> `! Tamper watch:` on proof card (`R-103` normal review, zero extra approval gate).

### 3.5 Typed owner resolution, waiver lifecycle (`R-143`) & bounded `R-178` durability (MAI F3, F4; GPT F7, F8)

1. **Closed typed owner resolution (`owners[].id`, MAI F3):**
   - `checks.<name>.owner?` and `health.indicators.<name>.owner?` must name one ID in `tenet.yaml` `owners[].id`; `areas.<name>.owners` (`kit/schemas/tenet-yaml.json:333`, never `area.owner`) holds `string[]` of policy owner IDs (when `areas` omitted, `CODEOWNERS` handles resolved strictly via `owners[].forge_accounts`/`id`).
   - Precedence: `allowed = indicator.owner ? [indicator.owner] : check.owner ? [check.owner] : area.owners`. **Empty or unresolved owner fails `TN-GATE-UNKNOWN`** (never synthetic `"Owner"` or blanket global `owners[]`).
   - **Waiver (`accept-health-regression`):** `Decision` (`kind: "waive"`, `forge-verified` via `owners[].forge_accounts`, `1-of-N` quorum across `allowed`, non-empty `reason`, mandatory `expiry` defaulting `issued_at + 30d <= waiver_max_days`). Reject `TN-DEC-ACTOR` for wrong-area owners and **`TN-GATE-SELF-WAIVE` (`R-203`)** for PR author, diff commit authors, `bots[]`/agents, or accounts whose bot opened the PR (`ci.md:209`).
2. **Waiver dispositions & `R-143` expiry (GPT F7):**
   - Claim disposition stays Kernel `waived` (`ALG-07:110`, **zero verified-change credit**). Live open-PR gates re-evaluate `now < expires_at` (`now >= expires_at` flips immediately to `failed` / `TN-WAIVER-EXPIRED`); historical replay preserves `waived` at `evaluated_at`.
   - Merging with a waiver appends an independent record `{exception_id, pr, integration_commit, area, indicator, baseline_digest_at_waive, shortfall, expires_at, status: "active"}` to `refs/tenet/records: health/exceptions.json`. Each `exception_id` closes **only** on verified `main` recovery meeting `baseline_digest_at_waive` or committed `reset_seq` (`change-policy`). When any unrecovered exception satisfies `now >= expires_at`, `area` flips to **`declined` (`expired-waiver`)**, blocking new `express`/`quick` intake and next gates (`verify`) under **`R-143`** until recovered or re-baselined.
3. **`R-178` bounded 30-day durability lineage (`ALG-17`, GPT F8 + MAI F4):**
   - **Authoritative integration stream:** `refs/tenet/records: works/*/events/*.json` (`work.closed` integration commits + `recorded_at`) cross-checked with `git log --first-parent` using strictly **`M^1..M`** (`ALG-15`, preventing feature-branch double counting; octopus merges `>2` parents -> `unknown`). Shallow or unrecorded history outputs `{status: "incomplete", coverage_pct, reason}` and never reports `100%`.
   - **Incremental state (`refs/tenet/records: health/durability-state.json`):** keyed by `(state_main_commit, state_digest)`, updated asynchronously on `main` recorder (never gates PRs) bounded per run to `max_commits_per_run = 250`, `max_diff_bytes = 50 MB`, `max_lines_per_commit = 20,000`, `60s` timeout (marking excess `incomplete`/`oversized_commit_truncated`). Tracks each surviving non-generated line (`<as_of>` `.gitattributes` `linguist-generated` + `ALG-11` exclusions) across `C_k^1..C_k` `-M50%` renames (`0` rewrite) and shifts (`0` rewrite), marking a rewrite/revert **once** and retiring cohorts at `merged_at + 30d < as_of` into immutable `(agent_definition, work_type)` totals (`CP-0037` join; absent attribution -> `"unknown"` with `missing_attribution_commits`). Output separates mature `[as_of - 60d, as_of - 30d]` from `provisional` `< 30d`; `lines_added === 0 -> durability_rate: null` (`not-applicable`).

### 3.6 Rolling noise counters & proof card (GPT F10, F12)

- **Owner routing & rolling 30d counters (`R-177`, `R-216`):** Route counters to `indicator.owner ?? check.owner ?? areas[area].owners[0]` (`TN-GATE-UNKNOWN` if empty). Key `not_useful` by `(work_id, indicator, fp_key)` and `false_blocks` by adjudicated `work_id` over `[as_of - 30d, as_of]` (`as_of` injected; re-evaluations do not inflate denominators; replaced findings start fresh keys): (1) `not_useful` (`> 10%`), (2) `waived`, (3) `overrides`, (4) adjudicated `false_blocks` (`> 2 / 100` flag per `R-216`). Require `minimum_sample: 20` evaluated changes (`10` surfaced findings for `not_useful`), emitting `"insufficient-sample"` below floor and `null`/`"n/a"` on `0` denominator.
- **Proof card (`contracts.md §5`, `ci.md:151`):** Fixed order `Health: <H> holding · <I> improved · <R> regressed · <W> waived · <U> unknown · <S> n/a` -> `blocking_regressed`, `tamper_watch`, `stale/config_changed/coverage_unverified/unknown`, `waived`, `advisory_regressed`, `improved`, collapsed `holding`. Shared head keeps $\lfloor(60000 - \text{overhead})/N\rfloor$; overflow writes full card to `refs/tenet/records: proof/<pr>/<evaluation_id>/health.md`, posting totals, blocking names, and link preserving true CI `conclusion`.
