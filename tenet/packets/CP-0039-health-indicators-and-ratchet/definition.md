## 1. Problem and outcome

Code health keeps software changeable (`V-V10`, `V-P9`) while existing debt never blocks unrelated edits (`V-M10`). Whole-repo thresholds stall work, offline lists see ~0% fix rates at Meta vs ~70% on diff-time review comments, noisy checks breed workarounds, and benchmarks measure agents gaming checks they can edit (30.4% in METR RE-Bench; 49%–76% in ImpossibleBench), motivating protected inputs and verifiable provenance rather than predicting Tenet's own rates.

**Outcome:** record existing debt in committed `.tenet/health-baseline.json`, block only unwaived regressions beyond policy tolerance on touched/area scope, start quiet in `observe` with an explicit `R-177` noise budget, guard the gate itself against tampering (`R-103`), and surface actionable health summaries on the proof card.

## 3. Core design

### 3.1 Committed baseline & indicator kinds (`R-175`, `R-176`)

- **Authoritative baseline (`.tenet/health-baseline.json` under `protect`):** Keyed by `"<area>::<indicator>"` (`{schema_version: 1, entries: {<key>: {area, indicator, kind, tool, tool_version, config_digest, scope_digest, value?, numerator?, denominator?, allowed_counts?: Record<fp_key, int>=0}}}`). Read from target `<base>` (`git show <base>:.tenet/health-baseline.json`); changed **only** by `change-policy` commit (`origin: observed` at adoption or explicit pruning/re-baselining). Missing entry for an enabled `enforce` indicator fails `TN-HEALTH-BASELINE` at `verify`/`assure` (optional stays `unknown`). If `finding_set` shows lower counts on touched files than committed `allowed_counts`, emit `"baseline stale"` (`advise`, never blocking fixes).
- **`scalar` (`health.indicators.<name>`):** `{kind: "scalar", population: "area" | "touched" | "sampled_runs", unit, direction: "up" | "down", tolerance: {kind: "absolute" | "relative-pct", value >= 0}, min_samples?, low_sample_under?: 20}`. ONLY `population: "area"` is `enforce`-eligible; `touched` and `sampled_runs` cap at `advise` (`0` lane credit). `scope_digest` hashes `{kind: "scalar", area, area_paths, area_source_digest, scope_globs, exclude_globs, unit}` (invariant to adding source files). Comparisons use exact `BigInt` cross-multiplied rationals (or scaled exact decimals; display rounding never flips verdicts); `relative-pct` at `baseline === 0` gives `0` slack; `denominator === 0` yields `not-applicable` iff `expected_paths` empty, else `TN-GATE-UNKNOWN`.
- **`finding_set` & `R-176` architecture (`rule_scope`):** Fingerprint `fp_key = sha256(RFC 8785 {rule_id, file, symbol: symbol ?? "", snippet_hash})` (`CRLF->LF`, collapsed horizontal spaces). Exact location duplicates (`rule_id, file, line, end_line, symbol, snippet_hash`) deduplicate to `1`. Exact `scope_digest` = `sha256(RFC 8785 {kind: "finding_set", area, area_paths, area_source_digest, scope, scope_globs, exclude_globs, rule_scope, check})`. Exact indicator-wide regression check:
  $$\text{excess\_total} = \sum_{k \in \text{in\_scope}} \max(0,\; \text{current}[k] - \text{allowance}[k]) \le \text{policy.max\_new}$$
  Improvements clamp at `0` so they never mask another key's regression; `max_new` is pinned solely in `<base>` `tenet.yaml`; `0` measurable scope yields `not-applicable`.
- **`R-176` architecture (`rule_scope: "architecture"`):** Target `<base>` owns `health.architecture.modules: {<id>: {paths, area?}}` (`TN-HEALTH-PROVENANCE` on mismatch). Core evaluates the single admitted report's sorted `architecture_graph: {modules, edges}` alongside edge violations within **`ci.md §5:185`'s honest limit** (detecting only **observable omissions**: declared partial coverage `coverage.complete === false`, a missing expected `<base>` module, or an unknown edge endpoint -> `TN-GATE-UNKNOWN`; silent edge omission by a `complete: true` producer is deferred to `CP-0064`). Tarjan SCC runs in $O(\lvert V \rvert+\lvert E \rvert)$, emitting `{kind: "cyclic_edge", rule_id: "r176-cycle", from_module, to_module}` for every edge inside a non-trivial SCC (`|SCC| > 1` or `u === v`) with at most 1 shortest lexicographic BFS cycle witness per SCC in `hint`. Unmapped areas fail `TN-GATE-UNKNOWN`.

### 3.2 Touched-scope rule (`ALG-15` in `src/specs/diff-mapper.ts`)

- Replaces private diff parsers in **both** `src/specs/touched.ts:88,112-178` and `src/reports/weakening.ts:164-230` (`ALG-08`, `ALG-09`, `ALG-14`, `CP-0036`, `CP-0039`).
- **Attribute & env isolation:** Runs `git` with `GIT_CONFIG_NOSYSTEM=1`, empty global config, `GIT_ATTR_NOSYSTEM=1`, `-c core.quotepath=false -c core.attributesfile= -c diff.algorithm=myers -c diff.renames=true -c diff.renameLimit=1000 -c diff.mnemonicPrefix=false -c diff.noprefix=false -c diff.relative=false diff --no-ext-diff --no-textconv --no-color --text -M50%` over `diff_base_sha..tested_sha` (`diff_base_sha = git merge-base base_sha tested_sha`, rejecting overflow on `renameLimit` as `unknown`). Inspects raw bytes via `catFileBatch`: blobs with `0x00` are `is_binary: true`; all non-NUL blobs produce UTF-8 hunks ignoring `.gitattributes` `binary`/`-diff`.
- **Scopes (`no 20-line skip`):** Zero `min_changed_lines` bypass on `enforce` (`low_sample: true` advisory badge below `20`).
  - **`touched_files` & `area` (`enforce`-eligible):** Baseline-relative multiset counts against committed `allowed_counts[k]` (within `(file_or_renamed_path, area, k)` where `-M50%` credit stays inside equal `area`s, and count-based `max(0, current_ref[k] - allowed_counts[k])` for `referenced_paths[]` deletion breaks).
  - **`touched_lines` (`metric_cap = "advise"` — advisory only in core):** Evaluates findings overlapping `[newStart, newEnd]` added/modified hunks (plus `referenced_paths[]`); unmodified shifted lines outside `-U0` hunks never trigger. Always capped strictly at `advise` (`0` gate credit / zero `enforce` blocks on edits inside legacy ranges); enforceable paired old/new hunk comparison and its base-side occurrence input contract move to `CP-0065`.

### 3.3 Rollout, applicability, `R-177` noise & tool-neutral inputs (`ci.md §2, §10`)

- **Precedence & applicability (`R-202`, `R-204`, `ALG-07`):** `effective_mode(I) = min(rule_mode("health-ratchet"), I.mode ?? "observe", metric_cap(I))` (new PR indicators default `observe` below `verify`, refused `TN-POLICY-RULE-DECISION` at `verify`; `metric_cap = "advise"` on all `touched`/`sampled_runs` scalars, **all** `touched_lines` finding sets, and **raw `lcov`/`cobertura` coverage**). Child `ALG-06` layers never narrow `scope_globs` or add `exclude_globs` (`TN-POLICY-LOOSEN`). Resolve indicator applicability first on pinned `<base>` facts (`R-202` touched `paths`/`scope_globs`/`!exclude_globs` or declared area dependencies via `ALG-15`); genuinely unknown applicability stays visible (`TN-GATE-UNKNOWN`), while inapplicable indicators resolve `not-applicable`. Check `checks.<name>` is mandatory (`verify` fails missing/malformed/`exit !== 0`) iff in `lane_checks` OR consumed by an **applicable** indicator `I` with `effective_mode(I) === "enforce"`. Missing/incomplete optional (`observe`/`advise`) health inputs yield `unknown` advisory without failing `verify`.
- **Tool-neutral inputs (`kit/schemas/health-input.json`, one report per check run):** `checks.<name>.report` accepts `tenet-health-json | sarif | lcov | cobertura`; each indicator binds one authoritative check (`no matrix shard combining` — differing duplicates fail `TN-HEALTH-INCOMPATIBLE`). **Tool identity (`name`, `version`, `config_digest`) comes solely from `<base>` `tenet.yaml`'s `checks.<name>` declaration, never from the report** and never copied from baseline. Only **`tenet-health-json` and `sarif`** reports carrying the required report metadata (`coverage: {complete, analyzed_paths/modules}` + `scope_digest`, checked against `<base>` `inputs[]`; drift -> `TN-HEALTH-CONFIG-CHANGED`, missing required metadata -> `TN-REPORT-MALFORMED` in `enforce`, else `unknown`; SARIF iterates all `runs[]`; any report supplying thresholds/`tolerance`/`max_new`/`mode`/`waived` fails `TN-REPORT-MALFORMED`) can be enforced. **Raw `lcov` and `cobertura`** normalize identically into advisory `area` scalar trends (`metric_cap = "advise"`, **0 gate credit**, never rejected for missing Tenet fields), taking `tool` from `<base>` `tenet.yaml` and naming missing report metadata explicitly (e.g., `missing_metadata: ["coverage.complete", "scope_digest"]`), subject to `ci.md §5:185`'s honest limit until `CP-0064`.
- **Owners & rolling `R-177` budget:** Resolve closed policy owner IDs `sortAscii(unique(indicator.owner ? [indicator.owner] : check.owner ? [check.owner] : areas[area].owners))` (`TN-GATE-UNKNOWN` when empty/unmapped). Track separate rolling-30d counters deduplicated by `(work_id, indicator, fp_key)` / adjudicated `work_id`: `not_useful` (`> 10%` flag), `waived`, `overrides`, and `false_blocks` (`> 2 / 100` `R-216` flag), requiring `minimum_sample` (`20` changes / `10` findings) before flagging.

### 3.4 Waivers, tamper check, determinism, proof card & dogfooding

- **`accept-health-regression` (`R-175`, `R-203`):** Kernel `Decision` (`kind: "waive"`, `expiry`, non-empty `reason`, `evaluation_id`, `forge-verified` via `1-of-N` `owners[].forge_accounts`, default `30d <= waiver_max_days`). Follows **`R-203` as written**: rejects wrong-area (`TN-DEC-ACTOR`) and, at `verify`/`assure`, rejects author/diff-committer/`bots[]`/agent self-waive (`TN-GATE-SELF-WAIVE`); **below `verify`** (`observe`/`protect`), a `forge-verified` owner self-waive is permitted and labelled `self-waived`. Preserves Kernel `waived` disposition (zero verified-change credit) for that evaluation; expired at `now >= Decision.expiry` -> `TN-WAIVER-EXPIRED`.
- **3-way `R-103` tamper check:** `.tenet/health-baseline.json`, `tenet.yaml`, workflows, `CODEOWNERS`, **`.gitattributes`**, and `protect` `inputs[]` -> `protected-surfaces` (`change-policy`); `ALG-09` test weakening + suppressions attributed to active pinned checks -> `tests-not-weakened` / `health-tamper`; unattributed markers, non-`protect` configs, and clean new tests -> diagnostic `! Tamper watch:`.
- **Determinism (`contracts.md §11`):** CRLF->LF, RFC 8785 digests, ASCII/`Buffer.compare` sorts, attribute-isolated `ALG-15`, exact `<base>`/`merge_base`, injected clock.
- **Proof card (`contracts.md §5`, `ci.md:151`):** `Health: <H> holding · <I> improved · <R> regressed · <W> waived · <U> unknown · <S> n/a` -> ordered sections (`blocking_regressed`, `tamper_watch`, `stale/config_changed/unknown`, `waived`, `advisory_regressed`, `improved`, collapsed `holding`), shared-head budget, and `refs/tenet/records` overflow preserving CI `conclusion`.
- **Dogfooding (non-normative):** Node `--experimental-test-coverage` LCOV (info-only `dist/` caveat unless `"sourceMap": true`), Biome cognitive complexity (`info`), suite time -> commit initial `.tenet/health-baseline.json` (`origin: observed`).
