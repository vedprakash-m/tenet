# CP-0044 · Round 2 specification questions

The independent fixture suite excludes outputs for the following undecided cases. No builder behavior was selected for them.

1. **Owner lookup with a section override.** ALG-03 (algorithms.md:53) says front matter precedes CODEOWNERS. Contracts §3 (contracts.md:38–54) allows both document and section owners. CP-0044's exports (alpha.0.md:103–113) name no owner lookup with a section input. Specify which function takes the section and precisely how it combines section and document metadata. The suite tests a single explicit front-matter owner.
2. **Rename precedence when current and blessed digests point to different candidates.** ALG-02 (algorithms.md:23) says a match can use either value and several candidates are ambiguous. It does not define whether a current-digest match ranks ahead of a blessed-digest match or which digest the returned record carries when both match. Add explicit precedence and output fields. The fixture for ambiguity uses two candidates for the same digest.
3. **Malformed citation diagnostic boundaries.** ALG-04 (algorithms.md:65–70) includes malformed syntax under `TN-CITE-RANGE` and separately defines document and test failures. Specify the diagnostic for malformed `doc:` or `test:` forms missing their required separators, and precedence when the path is also absent. The cases use unambiguous valid syntax or clearly invalid numeric bounds.
4. **Affected requirements when a section changes blessing state.** ALG-14 (algorithms.md:218–222) says scan head with base fallback for deleted documents, while the same algorithm also covers deleted requirements and sections. Specify whether a still-existing document's removed or downgraded requirement enters the result from the base and what reason applies. The fixture for deletion covers an entirely removed document.
5. **Touch ordering across distinct prefixes or equal numeric IDs.** ALG-14 (algorithms.md:218–222) orders by numeric ID within each reason. Contracts §1 (contracts.md:11) makes the prefix configurable. Define a tie break when historical records or a migration contain distinct prefixes with the same numeric suffix. The fixture tests numeric ordering under one prefix.
6. **Ownership of independent ALG-03 files.** CP-0044 lists ALG-03 in Needs and specifies anchors and relocation, but its Owns and Fixtures fields name only ALG-02, ALG-04 and ALG-14 (alpha.0.md:100–101, 121). Add the ALG-03 suite to the proving inputs while preserving independent ownership. The reviewer added this suite under the explicit round 2 assignment.
