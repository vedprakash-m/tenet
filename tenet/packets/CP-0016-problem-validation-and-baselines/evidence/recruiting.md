## Maintainer interview

Hi [name],

I'm interviewing maintainers who delegate real changes to coding agents. Would you be open to a 30-minute conversation about one recent change? I'd like to learn how you passed intent to the agent and decided what was ready. You can use any project you can discuss without sharing private code or credentials. Participation is optional, and I'll ask permission before taking notes or using a de-identified summary.

If you're interested, let me know your preferred times and the type of work you maintain.

Thanks,
