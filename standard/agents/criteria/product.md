# Product criteria

> Kit file · id `product` · version 0.1.0 · Applied by the judge at Shape and Review (Deep), and at Validate

| ID | Check | Default severity when violated |
|---|---|---|
| P1 | The change serves the vision items its packet names, and no boundary in the vision is crossed | Blocker |
| P2 | The behavior matches the requirement deltas as worded, not a reinterpretation | Blocker |
| P3 | Every acceptance example is covered by a test or a scenario | Major |
| P4 | Non-goals are respected; scope did not grow silently | Major |
| P5 | The Owner's time cost of the feature (decisions, maintenance) is stated where it is new | Minor |
