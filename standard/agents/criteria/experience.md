# Experience criteria

> Kit file · id `experience` · version 0.1.0 · Applied by the judge at Design and Review when the packet changes anything a person sees or types

| ID | Check | Default severity when violated |
|---|---|---|
| X1 | Wording matches the UX spec's vocabulary and voice | Minor |
| X2 | Every error says what failed, where, and how to fix it | Major |
| X3 | Every flow in the UX spec touched by the change still works end to end | Blocker |
| X4 | Meaning never depends on colour alone; text has sufficient contrast; keyboard use works | Major |
| X5 | Destructive or outward actions ask first and default to the safe choice | Blocker |
| X6 | The interface works at the narrowest supported width | Minor |
